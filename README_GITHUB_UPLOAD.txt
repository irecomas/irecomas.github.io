이레컴 GitHub Pages 최종 업로드용

1. GitHub 저장소의 기존 홈페이지 파일을 삭제합니다.
2. 이 ZIP을 압축 해제합니다.
3. 압축 해제된 파일을 저장소 최상위에 업로드합니다.
   - index.html
   - images/
   - .nojekyll
   - README.txt
   - README_GITHUB_UPLOAD.txt
4. Commit changes 합니다.
5. GitHub Pages는 main 브랜치 / root(/)로 배포합니다.

주의: ZIP 파일 자체가 아니라 압축을 푼 내부 파일을 업로드하세요.
